Blood, Steel and Ink

Completed: May 2023

Description

My final project for a 2D animation class, this game level was built on a
2D platformer template for Unity game engine. I was tasked to replace the
player character, enemies, environment, as well as adding a start screen.

The game follows a knight on a crusade to stop the demonic printers invading the kingdom.
I was inspired by printing issues I experienced earlier that week.
The course focused on animation, which caused the gameplay to suffer.
However, I have experience taking spritesheets and converting them into
animations in Unity.
