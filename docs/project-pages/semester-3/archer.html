Forest Hero

Completed: December 2023

Description

Forest Hero is a shoot 'em up style game made in JavaScript with the Pixi JS library.
It follows an archer character hunting monsters in the forest.
The player can scavenge for power-ups, granting either Triple-Shot or healing.
After defeating all monsters, the next wave starts.
Every 5th wave is a boss battle, where bosses have increasing amounts of health.
The game ends when the player runs out of health.
