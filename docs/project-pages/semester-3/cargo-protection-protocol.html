Cargo Protection Protocol

Completed: October 2023

Description

Cargo Protection Protocol is a space shoot 'em up made in Unity for a class project.
The player controls a starfighter tasked with protecting a cargo ship from
asteroids and bandit ships for 3 minutes.

The baseline project required a player controlled character moves via velocity vectors,
has the ability to shoot, has enemies to shoot at, and uses a collision system created
from scratch in C#. I opted to make my own pixel art and add the cargo ship as personal touches.
