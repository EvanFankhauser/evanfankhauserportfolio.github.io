Graphical Snake

Date Completed: April 2024

Description

A recreation of the classic Snake game, except it uses physics to move the character.
Made from C++ starter code with the Box2D and SFML libraries.
The player starts with a printed score, and each frame a movement key is held down, their score decreases.
The game ends when the player collects 10 targets.
Ideally, the player makes calculated moves to finish the game with the highest possible score.
